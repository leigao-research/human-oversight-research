# Smart Sustainable Cities

This section documents research on Operational Human Oversight in AI-enabled smart sustainable cities.

## ITU-T FG-AI4SSC

### FGAI4SSC-I-015

This work examines how Human Oversight mechanisms can be operationalized in AI-enabled urban systems.

Key areas include:

- intervention triggers
- escalation
- qualified human review
- human override
- traceable logging
- accountability
- return-to-operation processes
- human control in AI-enabled city systems
